# Moja vjeronauka — 6. i 7. razred

Interaktivni kviz za učenje i ponavljanje islamske vjeronauke.

- 6. razred: Moje potrebe i težnje, stranice 6–9.
- 6. razred: Ljut sam, jako sam ljut, stranice 30–32.
- 7. razred: Prirodno je težiti uspjehu, stranice 6–8.
- Odvojeni udžbenici i lekcije, sažeci, 40 pitanja po razredu, ajeti i hadisi, dopunjavanje riječi.

## Pokretanje

Otvorite index.html u pregledniku. Nije potrebna instalacija niti internetska veza.

Demonstracijska prijava: korisničko ime `ucenik`, lozinka `Vjeronauka67!`.
Prijava se provjerava u pregledniku i ne predstavlja zaštitu sadržaja. Rezultati se čuvaju samo tokom trenutnog korištenja stranice.

## GitHub Pages

U Settings → Pages izaberite Deploy from a branch, granu main i folder / (root), pa Save.
Svaka naredna izmjena na grani main automatski osvježava stranicu.

## Izvori

Sadržaj je pripremljen prema navedenim stranicama udžbenika. Izvorni PDF udžbenici nisu uključeni u ovaj repozitorij.
